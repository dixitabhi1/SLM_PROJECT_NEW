> [!IMPORTANT]
> **Fair Accounting & Latency Protocol:**
> - **Missing / Truncated Exclusions:** Items where a baseline failed to produce a valid, complete completion (`finish_reason != 'stop'`) are marked `MISSING` and excluded from valid head-to-head comparisons per Hard Rule 3 and Hard Rule 4.

On rate-limited compound items, total elapsed wall-clock duration includes automated backoff sleep waits (up to 75s per retry loop, reaching >2,000s wall-clock time). This reflects cloud API rate-limiting delays, not raw model forward execution time. Claims that the local SLM has higher raw throughput than 27B hardware are specifically withdrawn.
